# HMTc Pre-Build Protocol
## RETIRED — Content Absorbed into Step Zero Protocol
### Version 2.0 — April 2026
### Prepared by K. Pendergrass (CEO), K. Eyer, D. Aleru

---

**This document is retained for version history only. It no longer governs
any pipeline step.**

All Pre-Build Protocol content has been absorbed into the Step Zero
Protocol (v1.2+). The mapping:

| Former Deliverable | Now Lives In |
|-------------------|-------------|
| Deliverable 1: Category Confirmation | Step 0A (extract base subcategories from taxonomy) |
| Deliverable 2: Regulatory Authority Identification | Step 0E (web search identifies authorities during floor sourcing) |
| Deliverable 3: Regulatory Floor Values | Step 0E (Regulatory Floor Table) |
| Deliverable 4: Contamination Platform Identification | Step 0B (contamination platform splits) |
| Deliverable 5: Watch Items | Step 0E (Watch Items Table, produced during regulatory web search) |
| Deliverable 6: CC Source Data Package | Step 0F (Source CC Data) |

The pipeline no longer has a separate Phase 1 pre-build stage. Step 0
sources all data at runtime via web search.

---

## Why This Was Retired

The Pre-Build Protocol was written when the pipeline assumed:
- A supervised conversation would produce deliverables before automation
- Occurrence data sourcing required Perplexity deep research
- Human approval gates would separate phases

All three assumptions were eliminated when the pipeline moved to
end-to-end automated execution (Inngest). Step 0 now performs all
data sourcing, validation, and output production in a single automated
sequence.
